## 软件概述

在移动设备普及的当下，相册承载着用户最核心的个人生活记忆。商业相册软件普遍存在体积臃肿、开屏广告侵扰、权限过度索取以及人脸与媒体数据静默上云等问题。

**未来的相册 (FutureAlbum)** 是一款以“端侧计算、极致性能与隐私自主”为核心原则构建的下一代相册管理工具：

- **端侧处理与零云端依赖**：媒体索引、标签归类、OCR 字符识别与元数据解析 100% 在本地完成，不设任何远程用户数据采集服务。
- **高帧率渲染调优**：针对海量本地媒体（数万张规模）进行底层渲染与异步预取调优，提供稳定 60Hz/120Hz 高刷浏览体验。
- **专业级影像工具**：深度结合 EXIF 元数据解析、隐私脱敏伪装、复古点阵时间戳与 3D LUT 胶片色彩渲染。

## 核心特性

### 1. 极致性能与时间轴架构
- **双层缓存管线**：整合 LRU 内存缓存与自研本地缩略图磁盘持久化缓存，实现毫秒级异步加载与图像预热。
- **高刷新率支持**：针对海量本地数据针对性优化列表重组（Recomposition）与布局开销，保证高刷屏幕下的满帧滑动表现。
- **专业手势交互**：
  - 支持双指自由缩放网格跨度（Pinch-to-Zoom）；
  - 右侧悬浮快速时间滑块（FastScroller），按年份与月份快速定位；
  - 长按悬浮预览（Peek Overlay），松手即恢复，降低页面跳转开销；
  - 连续滑动多选（Drag Select），高效支持批量操作。

### 2. 离线端侧 OCR 与智能检索
- **本地 ML 引擎**：集成 Google ML Kit 离线中文/英文识别引擎，内置离线 C++ 算子动态库，完全无需网络连接。
- **低功耗后台索引**：基于 AndroidX WorkManager 分批次按需调度，采用让步休眠机制避免设备过热与性能损耗。
- **以图搜字穿透查询**：在顶部搜索栏输入发票单据、聊天截图、招牌或路牌文字，可毫秒级定位目标图片。
- **拼音与全文字典**：原生支持标签全拼、拼音首字母检索，提供精准的多维度过滤能力。

### 3. 复古胶片色彩与时间戳工坊
- **复古点阵液晶时间戳**：精准重现经典胶片机戳印质感，内置 LCD Dot、VCR OSD Mono、VHS 录像带三种字体渲染算法，支持琥珀橙、荧光绿、警示红多配色及倾斜度微调。
- **3D LUT 色彩渲染引擎**：内置专业级 3D LUT 色彩映射矩阵（包含 CPM35 与多款经典旁轴底片色调），实时预览并提供无损渲染输出。
- **参数卡水印边框**：支持定制化相机参数卡、经典摄影白底水印导出。

### 4. EXIF 深度解析与隐私保护
- **全量拍摄参数解析**：提取并结构化展示照片内置的全部元数据：
  - **器材信息**：相机品牌 (Make)、设备型号 (Model)、镜头规格 (Lens Model)
  - **光学与曝光**：光圈值 (Aperture)、快门曝光时间 (Shutter Speed)、感光度 (ISO)、物理焦距 (Focal Length)、35mm 等效焦距、曝光补偿 (EV)、测光模式、闪光灯状态、白平衡、色彩空间 (sRGB / Display P3)
  - **画面几何**：原始分辨率 (Width × Height)、有效总像素 (Megapixels)、画幅比例 (4:3, 16:9, 1:1)、文件大小与 MIME 类型
  - **时空属性**：精确拍摄时间（年月日时分秒）、时区、时段标识、相对时间周期
  - **地理位置**：GPS 经纬度、海拔高度（支持高原海拔/高空巡航识别）、拍摄指南针朝向方位、系统逆地理编码解析出的中文详细行政区划与街道地址
- **地图导航调用**：点击坐标与地址信息即可唤起本机地图应用实地查看。
- **EXIF 隐私脱敏与机型伪装**：
  - **一键抹除敏感数据**：一键彻底擦除照片中携带的 GPS 坐标、海拔高度与拍摄时间戳，阻断社交分享中的地理位置溯源；
  - **主流器材参数伪装**：支持一键将照片参数替换为哈苏 (Hasselblad X2D)、徕卡 (Leica M11 / Q3)、索尼 (Sony A7R V)、富士 (Fujifilm X100VI) 或 iPhone 16 Pro Max 等预设机型。

### 5. 视频播放与防误删安全体系
- **硬件解码播放**：依托 AndroidX Media3 ExoPlayer 提供流畅的本地视频硬解播放与悬浮窗预览。
- **双重删除防护**：严格分离软删除与物理清除；内置“摇一摇撤销”（Shake to Undo）机制，误删操作可在数秒内无损回滚。

## 操作指南

### 1. 画廊与时间轴手势
- **切换网格列数**：在时间轴主视图中，使用双指做张开或捏合动作，可在 3 列、4 列、5 列网格布局之间平滑切换。
- **快速时间跳转**：按住屏幕右侧浮动的垂直滑块（FastScroller）上下拖曳，中心区域会即时浮现对应的年份与月份，支持快速定位历史月份。
- **长按悬浮预览 (Peek)**：无需点入大图，在网格中**长按任意一张照片**即可直接悬浮弹出高清画面预览；手指离开屏幕即自动关闭。
- **连续滑动多选**：点击右上角“选择”按钮后，手指按住某张图片并顺势滑动，即可快速连续多选一组照片。
- **媒体类型过滤**：轻触顶部的筛选胶囊，可快速筛选：`全部`、`图片`、`视频`、`GIF动图`、`未标记标签`。

### 2. 离线以图搜字与拼音检索
- **图像内文字检索**：点击顶栏搜索框，直接键入想要寻找的照片内文字（例如发票商家名称、聊天截图对话关键词、文档标题），系统将通过本地 OCR 数据库自动筛选包含该文字的照片。
- **拼音标签过滤**：输入标签全拼或首字母（如输入 `fj` 或 `fengjing`），即可快速定位关联了 `#风景` 标签的所有照片。

### 3. 查看 EXIF 元数据与地图定位
- **展开参数卡片**：进入单张照片全屏查看状态，**向上轻滑屏幕**或点击底栏 **信息 (i)** 图标，即可呼出详细的拍摄参数列表。
- **地图实景导航**：如果照片内嵌了地理信息，卡片中会显示解析后的省市区街道地址与罗盘朝向；点击地址即可直接唤起手机自带的地图 App 查看精确坐标。

### 4. EXIF 隐私脱敏与机型伪装
- **呼出伪装控制面板**：在单张照片详情页中，点击底栏操作栏中的 **修改 EXIF / 隐私伪装** 按钮。
- **抹除敏感数据**：勾选“抹除 GPS 经纬度”与“重置拍摄时间”，确认后将生成无位置追踪属性的干净副本。
- **更换拍摄机型**：在预设列表中选取目标设备（如 Leica M11 或 Hasselblad X2D），应用后照片的制造厂商、机型与镜头参数将被即时替换。

### 5. 胶片调色与复古时间戳工坊
- **进入图像编辑**：在大图界面点击底栏 **编辑** 按钮。
- **启用复古时间戳**：
  - 勾选开启时间戳；
  - 挑选字体风格（LCD Dot 点阵液晶、VCR OSD Mono 录像带、VHS 怀旧模式）；
  - 切换印记色彩（经典琥珀橙、荧光亮绿、警示鲜红）并按需调整倾斜度。
- **应用 3D LUT 胶片滤镜**：点击色彩栏目，左右滑动选取经典旁轴与胶卷色彩预设，查看无损渲染效果。
- **保存导出**：点击右上角确认保存，系统将在保护原始文件的同时输出高质量处理后图片。

### 6. 多维标签与智能相册
- **批量设置标签**：在多选状态下点击底栏“打标签”，勾选对应分类下的标签即可批量赋标。
- **智能相册归纳**：切换到底部“相册”界面，支持创建基于拍摄设备型号、拍摄日期区间或多标签交集的自定义规则相册。

### 7. 摇一摇撤销误删
- **误删立即恢复**：如果不慎误删除了重要照片，在 5 秒内**轻摇手机**，应用将通过触觉震动反馈并弹出撤销确认提示，点击确认即可瞬间复原。
- **回收站二次管理**：从侧栏或相册页面进入“回收站”，可对已被软删除的照片进行按需批量还原或物理彻底清除。

## 技术架构

| 模块分层 | 核心技术选型 | 说明 |
| :--- | :--- | :--- |
| **开发语言** | Kotlin 2.0+ (JVM 21) | 强类型现代化语言及协程支持 |
| **用户界面** | Jetpack Compose, Material 3 | 声明式响应式 UI 体系 |
| **架构模式** | MVVM + 单向数据流 (UDF) | 状态流 (StateFlow) 与事件驱动驱动模型 |
| **本地存储** | Room Database + KSP | 结构化本地关系型数据库与索引优化 |
| **图像管线** | Coil 3 | 跨格式渲染（静图、GIF、视频第一帧抽帧）与双级缓存 |
| **媒体引擎** | AndroidX Media3 ExoPlayer 1.5.1 | 现代化硬解视频播放架构 |
| **端侧 AI** | Google ML Kit (Text Recognition Chinese) | 完全离线 C++ 算子模型中英文端侧识别 |
| **任务调度** | AndroidX WorkManager | 低功耗增量式后台任务编排 |
| **中文检索** | Pinyin4j 2.5.1 | 多音字与拼音首字母检索适配 |
| **适配标准** | CompileSdk 35 / MinSdk 26 / TargetSdk 35 | 全面兼容 Android 15 Edge-to-Edge 沉浸规范 |

## 项目结构

```tree
app/src/main/java/com/example/phototag/
├── data/
│   ├── dao/             # Room 数据库访问对象 (PhotoDao, TagDao)
│   ├── entity/          # 数据实体模型 (PhotoEntity, TagEntity, CrossRef)
│   ├── ocr/             # Google ML Kit 离线文字识别封装 (OcrManager)
│   ├── repository/      # 数据仓库层 (统一调度 MediaStore 与本地数据库)
│   └── worker/          # 后台异步低功耗索引任务 (MediaIndexWorker)
├── ui/
│   ├── components/      # 解耦的 Compose 基础组件 (时间轴、手势面板、弹窗)
│   ├── screen/          # 顶层功能界面 (PhotoListScreen, PhotoViewerScreen, ImageEditScreen 等)
│   └── theme/           # Material 3 主题系统、配色配置与排版阶梯
└── util/
    ├── editor/          # 滤镜色彩映射引擎、复古点阵时间戳与参数卡渲染
    ├── exif/            # EXIF 解析器、元数据修改与伪装脱敏引擎
    └── ...              # 拼音检索、触觉反馈、缩略图预加载等辅助工具
```

## 编译与运行

如需从源代码构建并打包应用：

1. **环境准备**：
   - 安装最新版 [Android Studio](https://developer.android.com/studio) (Koala 或 Ladybug 以上版本)
   - 配置 **JDK 21**
   - 通过 Android Studio SDK Manager 安装 **Android SDK Platform 35**

2. **克隆代码库**：
   ```bash
   git clone https://github.com/uminrae/FutureAlbum.git
   cd FutureAlbum
   ```

3. **执行编译构建**：
   ```bash
   # 构建 Debug 开发版本
   ./gradlew assembleDebug

   # 构建正式 Release 优化版本
   ./gradlew assembleRelease
   ```
   *编译产物 APK 位于 `app/build/outputs/apk/` 目录下。*
